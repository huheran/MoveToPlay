# MoveToPlay USB Dongle

The original exports named `SW1`, `SW2`, and `SW3` are retained as chronological hardware revisions:

- `rev-a/`: original `Dongle_SW1.eprj2` export.
- `rev-b/`: original `Dongle_SW2.eprj2` export.
- `rev-c/`: original `Dongle_SW3.eprj2` export and the newest snapshot.

Use Rev C unless compatibility with an earlier physical build requires another revision.
